# 渐进阅读 · 章末小测

> **文档同步日期：2026-08-01**
> **状态：landed（Custom Panel 专注答题 + 揭晓后扁平意图条；共享生成取消 / live 同步 / 错题回看制卡；制卡落点=出处块 + 只剩 Panel 时自动打开原文面板；「原文」跳转优先左侧 srs.ir-session 阅读面板，无阅读面板才开/复用右侧侧栏）**
> 与日常 SRS `#choice` 选择题卡 / AI 快捷制卡路径**独立**。

## 目的

用户在 **Topic / 章节** 阅读完毕后，根据**本章全文**自动生成一次性单选题，检验理解。
测验为一次性检查：测完可删，**不**进入题库温习，**不**自动进入 FSRS 复习队列。

## 用户入口

| 入口 | 行为 |
|------|------|
| 右侧动作栏 **完成** → 完成确认成功后 | Topic：IR 已归档/移出，**会话 UI 暂不切下一篇**；再弹「章末小测」确认 |
| **⋯ 更多 → 章末小测**（仅 Topic） | 直接弹同一确认框（不归档、不 hold） |
| 斜杠 **GOTIT?** | 任意页面：以当前编辑器 `rootBlockId` 为源，页面底部插入小测 |

确认文案见 `CHAPTER_QUIZ_COPY`（`src/srs/incremental-reading/chapterQuiz.ts`）。

用户点 **开始出题** → 在该 Topic/页面 **末尾**插入 `srs.chapter-quiz` 块并开始生成。

**完成后续停留（postCompleteQuizHold）**：

1. `performArchive` 成功且 `leftCard` → 写库移出 IR 队列（正确）
2. **不**立刻 `removeCurrent`，继续显示本章正文，等用户出题/作答
3. 用户选「暂不需要」→ 再 `removeCurrent` 进下一篇
4. 用户选「开始出题」并测完 → 结束态 **继续下一篇**（或动作栏「下一篇」）再推进会话
5. hold 期间「下一篇/完成」只推进 UI，不再 `performNext`（避免对已归档章二次排期）

## 内容范围

- **仅当前 Topic 子树全文**（BFS，有界：深度 / 块数 / 字符）
- **不**发送整本书
- 收集时跳过已存在的章末小测块子树，避免旧测验污染源文本

常量：`CHAPTER_QUIZ_SOURCE_MAX_*`（同文件）。

## 测验体验（UX）

### 双界面分工（无双活答题）

| 界面 | 职责 |
|------|------|
| 原文中的 `srs.chapter-quiz` **块** | **紧凑入口**：生成中 / 失败重试 / 待开始·继续（带进度）/ 已完成摘要。**不**展示完整选项、追问、制卡 UI |
| **Custom Panel** `srs.chapter-quiz-panel` | **唯一完整答题界面**；右栏打开，**左栏保持 `srs.ir-session`** |

`openChapterQuizInSidePanel` 导航：

- `view: CHAPTER_QUIZ_PANEL_VIEW`（`srs.chapter-quiz-panel`）
- `viewArgs: { quizBlockId }`
- 无右栏则 `orca.nav.addTo(host, "right", …)`；已有右栏则 `goTo` 复用
- 打开/复用后派发 `CHAPTER_QUIZ_PANEL_NAV_EVENT`（`panelId` + `quizBlockId`），避免 Custom Panel 不 remount 时仍显示旧测验
- **不** `goTo` 左侧，避免顶掉渐进阅读

Panel 仅接收 `PanelProps`（`panelId` 等），**必须**：

1. 首次从 `resolveQuizBlockIdForPanel(panelId)` 读 `viewArgs.quizBlockId`
2. 监听 `CHAPTER_QUIZ_PANEL_NAV_EVENT` 更新 local `quizBlockId`（`key={quizBlockId}` 重置体验状态）
3. 缺失/非法 id 时显示错误态（不空白、不伪装成功）

### 共享生成与 live 同步（同进程）

| 机制 | 行为 |
|------|------|
| **共享生成** `chapterQuizLive` | 同一 `quizBlockId` 共用 `AbortController` + `generationId`；block/panel 任一取消都能中止在途请求；取消后迟到结果不得写回 quiz 成功态；**卸载某一实例不 abort** 仍由另一实例等待的共享生成 |
| **Live 同步** | `persist` 成功前/广播 `publishQuizLive`；其它 controller 订阅同 blockId 更新本地 repr（**不**新建持久化；后端仍是 `srs.chapterQuiz`）；跳过发布方自身防回环；卸载对称 `unsubscribe` |

### 专注主路径（Panel）

每次只有一个主任务：

1. **答题前**：标题/进度、题干、选项
2. **答题后**：正确/错误、正确答案（错题强调）、简洁讲解；**唯一高强调主操作**是「下一题 / 完成本轮」（sticky solid CTA）
3. 揭晓后在反馈与主 CTA 之间出现**扁平意图动作条**（方案 A），**不再**套「深入理解」大折叠

#### 意图动作条（揭晓后）

三个动词入口，默认展开 0 层：

| 入口 | 行为 |
|------|------|
| **加入复习**（split） | 主按钮 = **一键简答卡**；`▾` 展开菜单：简答 / 填空（填空仍预览确认） |
| **问 AI** | 原地展开追问区；助手回复轻量 Markdown（`renderLightMarkdown`） |
| **原文** | 左侧有 `srs.ir-session` 阅读面板时：请求该面板在正文内 scroll+高亮定位出处块（`CHAPTER_QUIZ_LOCATE_EVENT`，**定向**到左侧面板，不新增侧栏、不 `goTo` 改写阅读面板）；**无**阅读面板时才在**侧栏**打开出处 block 视图（`addTo` 相对答题 Panel 向右；复用已打开出处侧栏 / 本会话缓存，避免叠出三块面板） |

- **对题**默认顺序：加入复习 → 问 AI → 原文（偏捕获）
- **错题**默认顺序：原文 → 问 AI → 加入复习（偏理解）
- 无 `sourceBlockId`：仅禁用「加入复习」并短提示，不隐藏整条工具栏
- 换题 / 错题游标切换：收起意图面板，清空临时追问 UI
- 展开「问 AI」或「加入复习 ▾」菜单后：`scrollIntoView` 把展开区滚入视野，并聚焦追问输入框（避免被 sticky「下一题」挡住、需手滑）
- 视觉层级：意图 chip 为 outline/sunken；**不得**与「下一题」同权 solid

### 完成本轮与错题回看

- 分数、错题数、主操作「继续下一篇 / 删除测验」
- **回看错题**：只读逐题浏览；**每一道** active 错题共用同一意图条：原文、问 AI、加入复习（简答/填空）
- 辅助 API **显式接收目标 question**（`handle*For(question, …)`），不隐式绑定 `currentIndex`
- 追问历史为临时 UI：切换错题时清空可接受；请求上下文必须是当前回看题
- 制卡写入 `repr.cardAdds[activeQuestion.id]`，不得写到最后一题
- **不**改变既有 `answers` / `revealed` 语义
- **Custom Panel 制卡**：
  1. 写卡函数 **不**用 `invokeGroup`（Panel 无编辑器事务组）；顺序 `insertBlock` / `insertTag` / SRS；失败删顶层新块；**禁止**抛错后重跑 callback。
  2. 真机证据：`activePanel` 在 `srs.chapter-quiz-panel` 时 `insertBlock` 返回 `undefined` 且不写入；短暂 `switchFocusTo` 同布局左侧可写 ViewPanel 后写入成功。
  3. `runWithChapterQuizEditorContext`（`chapterQuizEditorContext.ts`）：从面板**树**解析 Custom Panel 之前最近的可写 ViewPanel（支持嵌套 Row/Column，拒绝 quiz panel 自身）→ 保存原焦点 → `switchFocusTo` → **有界等待** `activePanel` 到位，并留出 150ms 宿主编辑器稳定窗口后再次确认焦点（超时/漂移均不执行 task）→ 在同一上下文内完成**写卡 + `cardAdds` persist** → `finally` 恢复右侧；恢复失败 `console.error`，不覆盖制卡错误。不导航、不滚动、不改面板内容。
  4. `useChapterQuizController({ writeContextPanelId: panelId })` 由 `ChapterQuizExperience` 传入；块侧入口不传。
  5. **制卡落点 = 当前题 `sourceBlockId`**（与「原文」同一来源）：简答/填空卡作为该原文块的**子 block**（`lastChild`）写入，紧邻出题依据。`requireQuizCardSourceBlockId` 校验缺失/非法 ID；缺失时「加入复习」禁用并提示，`sourceBlockId` 对应块已删除时写卡函数报「父块不存在」，**绝不退回 Topic 猜位置**。
  6. **只剩 Custom Panel 时自动打开原文 Block Panel**：`resolveChapterQuizEditorHostPanelId` 找不到可写 ViewPanel 时，`runWithChapterQuizEditorContext` 使用 `openPanel`（`{ view: "block", viewArgs: { blockId: sourceBlockId } }`）经 `orca.nav.addTo(panelId, "left", …)` 自动打开相邻普通 Block Panel 并导航到出处块 → 有界等待新面板挂载（`waitForPanelInTree`）→ 切焦点 → 写卡 → 恢复右侧；Custom Panel **不被 `goTo` 顶掉**，新面板制卡后**保留**（默认建议）。打开失败 / 挂载超时均显式报错，task 只执行一次。

### 其它

- 默认 **10** 道 **单选**；点选后立即锁定揭晓
- 生成中可 **取消**；失败自动重试最多 **3** 次（外层预算，`callChatCompletions` 传 `maxRetries: 0`）后提示 **重新生成**
- 本轮结束后可 **删除测验**；入队闪卡与测验块解耦
- 完成入口：仅当 `performArchive` 结果 `leftCard === true` 才弹小测
- 布局：Panel 撑满自身可用高度；内容 `max-width` 克制（约 36rem）；适应窄右栏；Wide View 仍由宿主控制

### 块表示

**`_repr`（轻量，仅渲染类型）**

```ts
{
  type: "srs.chapter-quiz",
  pluginName: string,
  topicBlockId: number,
  phase: "generating" | "quiz" | "done" | "error",
  questionCount: number,
  sessionContinueNext?: boolean
}
```

**属性 `srs.chapterQuiz`（JSON / Text 回退）** — 题目、答题进度、入卡记录等重状态。
禁止把整套 `questions` 塞进 `_repr`。

状态写回：`saveChapterQuizRepr` → `setProperties(srs.chapterQuiz)` + 同步 live 轻量 `_repr`；写后保持 `invalidateBlockCache`。

Custom Panel **复用同一持久化**，不另建平行数据源；live 广播只同步内存 UI。

## 边界与非目标

- **不**生成多选 / 简答题型（首版仅单选）
- **不**把小测题直接变成 `#choice` SRS 卡
- **不**维护跨会话题库 / 随机温习
- 源文本与 AI 输出均按「不可信数据」进 prompt（BEGIN/END 分隔）
- 错误可见：生成/写卡/保存/取消失败均 `console.error` + notify，不静默吞掉
- 原文块与 Custom Panel **不可同时**作为 live 答题 UI（块侧已收敛为入口）
