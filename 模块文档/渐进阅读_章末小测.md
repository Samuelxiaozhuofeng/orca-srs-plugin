# 渐进阅读 · 章末小测

> **文档同步日期：2026-08-01**  
> **状态：landed（首版）**  
> 与日常 SRS `#choice` 选择题卡 / AI 快捷制卡路径**独立**。

## 目的

用户在 **Topic / 章节** 阅读完毕后，根据**本章全文**自动生成一次性单选题，检验理解。  
测验为一次性检查：测完可删，**不**进入题库温习，**不**自动进入 FSRS 复习队列。

## 用户入口

| 入口 | 行为 |
|------|------|
| 右侧动作栏 **完成** → 完成确认成功后 | Topic：IR 已归档/移出，**会话 UI 暂不切下一篇**；再弹「章末小测」确认 |
| **⋯ 更多 → 章末小测**（仅 Topic） | 直接弹同一确认框（不归档、不 hold） |
| 斜杠 **GOTIT?** | 任意页面：以当前编辑器 `rootBlockId` 为源，页面底部插入小测 |

确认文案见 `CHAPTER_QUIZ_COPY`（`src/srs/incremental-reading/chapterQuiz.ts`）。

用户点 **开始出题** → 在该 Topic/页面 **末尾**插入 `srs.chapter-quiz` 块并开始生成。

**完成后续停留（postCompleteQuizHold）**：

1. `performArchive` 成功且 `leftCard` → 写库移出 IR 队列（正确）  
2. **不**立刻 `removeCurrent`，继续显示本章正文，等用户出题/作答  
3. 用户选「暂不需要」→ 再 `removeCurrent` 进下一篇  
4. 用户选「开始出题」并测完 → 结束态 **继续下一篇**（或动作栏「下一篇」）再推进会话  
5. hold 期间「下一篇/完成」只推进 UI，不再 `performNext`（避免对已归档章二次排期）

## 内容范围

- **仅当前 Topic 子树全文**（BFS，有界：深度 / 块数 / 字符）
- **不**发送整本书
- 收集时跳过已存在的章末小测块子树，避免旧测验污染源文本

常量：`CHAPTER_QUIZ_SOURCE_MAX_*`（同文件）。

## 测验体验

- 默认 **10** 道 **单选**
- **一题一题**展示；点选后立即锁定并揭晓：对/错、正确答案、讲解
- **主操作条**固定在选项正下方：揭晓后左侧 **简答 / 填空**，右侧 **下一题**；追问区在其下、**固定高度内部滚动**，不再把主按钮顶出视口
- 揭晓后：
  - **加入简答卡**（一键，题干→正面，正确项+讲解→背面；写入 Topic 下真实 `#card` basic）
  - **做成填空卡**（轻量 AI 改写 → 迷你预览可编辑 → 确认写入 cloze）
  - **追问**框（上下文为当前题 + 作答 + 讲解）
- **侧栏答题（方案 B）**：`openChapterQuizInSidePanel` → 右栏小测 + **左栏打开 Topic 原文**；用户手动点「侧栏答题」
- **跳转原文**：收集源文时标注 `[block:id]`；AI 每题回传 `sourceBlockId`（须落在收集 ID 集合内）；揭晓后显示「跳转原文」→ `jumpToQuizSourceBlock` 在左侧面板 `goTo` 该块
- 生成中可 **取消**；失败自动重试最多 **3** 次（外层预算，`callChatCompletions` 传 `maxRetries: 0`，避免层叠）后提示 **重新生成**
- 本轮结束后可 **删除测验**；入队的闪卡与测验块解耦，删测验不删卡
- 完成入口：仅当 `performArchive` 结果 `leftCard === true`（当前章已离开队列）才弹小测；顺序书 `partial` 且章未剥离时不弹

### 块表示

**`_repr`（轻量，仅渲染类型）**

```ts
{
  type: "srs.chapter-quiz",
  pluginName: string,
  topicBlockId: number,
  phase: "generating" | "quiz" | "done" | "error",
  questionCount: number,
  sessionContinueNext?: boolean
}
```

**属性 `srs.chapterQuiz`（JSON / Text 回退）** — 题目、答题进度、入卡记录等重状态。  
禁止把整套 `questions` 塞进 `_repr`（宿主对特殊 `_repr` 写大对象易失败 →「小测状态保存失败」）。

状态写回：`saveChapterQuizRepr` → `setProperties(srs.chapterQuiz)` + 同步 live 轻量 `_repr`。

## 边界与非目标

- **不**生成多选 / 简答题型（首版仅单选）
- **不**把小测题直接变成 `#choice` SRS 卡
- **不**维护跨会话题库 / 随机温习
- 源文本与 AI 输出均按「不可信数据」进 prompt（BEGIN/END 分隔）
- 错误可见：生成/写卡/保存失败均 `console.error` + notify，不静默吞掉
