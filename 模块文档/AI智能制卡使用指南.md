# AI 生成闪卡使用指南

> 文档同步日期：2026-08-10
> 变更说明：未配置 API Key 时直达「连接」设置；生成后遇到 401/403 时保留错误并提供显式设置入口。

## 功能概述

**AI 生成闪卡** 根据**当前光标块**文本，调用 OpenAI 兼容服务生成 Basic/Cloze 草稿；在弹窗中检查、编辑、勾选后确认写入。

实现见 [SRS_AI模块.md](./SRS_AI模块.md)。

## 配置

| 项 | 说明 |
| --- | --- |
| API Key | 必填 |
| API URL | 完整 chat/completions URL（勿用 Ollama `/api/chat`） |
| AI Model | 模型名 |
| 模型原生联网 | 可选勾选；开启后按 model 自动：Grok 4.5 → `web_search`，Gemini Flash → nested `google_search`；其它模型不挂 tools（无需选手动形态） |
| 思考强度 | 可选；`default` / `low` / `medium` / `high`（后三者写入 `reasoning_effort`） |

入口：**AI / Firecrawl 服务设置**（Headbar 插头图标或斜杠）。命令面板 **「SRS: 测试 AI 连接」** 可探活（有超时；测连不触发联网 tool）。

若尚未配置 API Key，直接触发「AI 生成闪卡」、AI 快捷交互或快捷制卡，会一步打开服务设置的**「连接」**页，无需再从插件设置中查找入口。

## 使用

1. 光标放在有文本的块上
2. `/AI 生成闪卡` 或命令面板「SRS: AI 生成闪卡」
3. 选 Basic/Cloze 与最多 1/3/5 张 → 生成草稿（可取消；错误保留弹窗）
4. 预览中编辑/勾选；已选无效草稿会显示行内错误，保存按钮不可用
5. **保存 N 张** 才写库；关闭不写

若对话框已打开，再次触发命令会提示先关闭，避免覆盖进行中的生成或预览。

## 写入与失败

- 成功：整批一步撤销
- 失败：尝试删除本批新卡（尽力而为，非硬事务）；若仍有残留，弹窗/通知会列出块 ID，请手动检查删除
- 生成请求返回 **401/403**：原错误仍保留在当前生成界面，并显示「打开连接设置」。只有点击该动作后才会先关闭当前生成弹窗、再切到连接设置，不会叠加两个模态。
- 其它 HTTP 错误、超时、解析或写入错误：不显示设置入口，继续沿用原错误信息与重试方式。

## 注意事项

1. 仅当前块文本
2. 模型输出须接地（依据摘录、Basic 答案来自依据、Cloze 全文为源摘录）
3. 语言跟随源文本
4. Azure 仅 `api-key` 头时不支持
